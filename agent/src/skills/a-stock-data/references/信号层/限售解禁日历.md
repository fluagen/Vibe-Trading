# 限售解禁日历

> **Vibe-Trading 内置**: 此功能已由 `eastmoney` 技能的 `get_lockup_expiry` 工具覆盖。

## 功能说明

查询个股历史限售解禁记录 + 未来 N 天待解禁批次。解禁预警必备，用于评估未来抛压。

## 数据源

- **端点**: `https://datacenter-web.eastmoney.com/api/data/v1/get`
- **报表名**: `RPT_LIFT_STAGE`
- **鉴权**: 零鉴权，走 `eastmoney_datacenter` 统一入口（自动限流）

## 请求参数

| 参数 | 值 | 说明 |
|------|-----|------|
| `reportName` | `RPT_LIFT_STAGE` | 限售解禁报表 |
| `filter` | `(SECURITY_CODE="{code}")` | 按股票代码过滤 |
| `pageSize` | `15-20` | 历史15条/未来20条 |
| `sortColumns` | `FREE_DATE` | 按解禁日期排序 |
| `sortTypes` | `-1`(倒序) / `1`(正序) | 历史倒序/未来正序 |

## 返回字段

| 字段 | 含义 |
|------|------|
| `FREE_DATE` | 解禁日期 |
| `LIMITED_STOCK_TYPE` | 限售股类型 |
| `FREE_SHARES_NUM` | 解禁数量(股) |
| `FREE_RATIO` | 解禁占总股本比例 |

## 限售股类型参考

- 首发原股东限售股份（IPO 后 1-3 年）
- 首发机构配售股份（IPO 战略配售）
- 定向增发机构配售股份（6-18 个月）
- 股权激励限售股份

## 代码示例

```python
from datetime import datetime, timedelta

def lockup_expiry(code: str, trade_date: str, forward_days: int = 90) -> dict:
    """限售解禁日历。返回: {history: [...], upcoming: [...]}"""
    # 1. 历史解禁记录
    history_data = eastmoney_datacenter(
        "RPT_LIFT_STAGE",
        filter_str=f'(SECURITY_CODE="{code}")',
        page_size=15,
        sort_columns="FREE_DATE", sort_types="-1",
    )
    history = []
    for row in history_data:
        history.append({
            "date": str(row.get("FREE_DATE", ""))[:10],
            "type": row.get("LIMITED_STOCK_TYPE", ""),
            "shares": row.get("FREE_SHARES_NUM", 0),
            "ratio": row.get("FREE_RATIO", 0),
        })

    # 2. 未来待解禁
    end_date = datetime.strptime(trade_date, "%Y-%m-%d") + timedelta(days=forward_days)
    end_str = end_date.strftime("%Y-%m-%d")
    upcoming_data = eastmoney_datacenter(
        "RPT_LIFT_STAGE",
        filter_str=f'(SECURITY_CODE="{code}")(FREE_DATE>=\'{trade_date}\')(FREE_DATE<=\'{end_str}\')',
        page_size=20,
        sort_columns="FREE_DATE", sort_types="1",
    )
    upcoming = []
    for row in upcoming_data:
        upcoming.append({
            "date": str(row.get("FREE_DATE", ""))[:10],
            "type": row.get("LIMITED_STOCK_TYPE", ""),
            "shares": row.get("FREE_SHARES_NUM", 0),
            "ratio": row.get("FREE_RATIO", 0),
        })

    return {"history": history, "upcoming": upcoming}

# 用法
data = lockup_expiry("002475", "2026-05-17")
print(f"历史解禁 {len(data['history'])} 批")
for h in data["history"][:5]:
    print(f"  {h['date']}: {h['type']} 数量={h['shares']}")
if data["upcoming"]:
    print(f"未来90天待解禁 {len(data['upcoming'])} 批")
else:
    print("未来90天无待解禁")
```
