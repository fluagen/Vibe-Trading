# 同花顺北向资金 — 实时分钟流向 + 本地自缓存历史

> **Vibe-Trading 内置：** 北向资金流向数据暂无内置工具覆盖。注意：eastmoney 全系北向数据自 2024-08 后净买额字段返回 NaN/0，属上游断供。本端点（同花顺 data.hexin.cn）是当前唯一可用的实时北向资金数据源。

## 概览

- **端点：** `https://data.hexin.cn/market/hsgtApi/method/dayChart/`
- **协议：** HTTP GET，JSON 返回
- **时间覆盖：** 当日实时分钟级（含集合竞价 09:10–15:00，262 个时间点）
- **封 IP 风险：** 低
- **鉴权：** 需带 `Host: data.hexin.cn` 和 `Referer: https://data.hexin.cn/`

## 参数

无需参数。直接 GET 即可获取当日实时分钟流向。

## 返回字段

| 字段 | 含义 | 单位 |
|------|------|------|
| `time` | 时间点列表 | `HH:MM` 格式，约 262 个 |
| `hgt` | 沪股通累计净买入 | 亿元 |
| `sgt` | 深股通累计净买入 | 亿元 |

## 本地自缓存

由于历史数据无法从上游获取，每次调用实时接口后自动写入本地 CSV（`~/.tradingagents/cache/northbound_daily.csv`），历史数据越跑越丰富。

缓存文件格式：
```
date,hgt,sgt
2026-05-15,12.34,-5.67
2026-05-16,8.90,3.21
```

## 代码示例

```python
import requests
import pandas as pd
from pathlib import Path

HSGT_HEADERS = {
    "User-Agent": (
        "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
        "Chrome/117.0.0.0 Safari/537.36"
    ),
    "Host": "data.hexin.cn",
    "Referer": "https://data.hexin.cn/",
}

def hsgt_realtime() -> pd.DataFrame:
    """
    沪深股通当日实时分钟流向（含集合竞价 09:10–15:00，262 个时间点）。
    返回字段: time, hgt(沪股通累计净买入), sgt(深股通累计净买入)
    单位: 亿元
    """
    url = "https://data.hexin.cn/market/hsgtApi/method/dayChart/"
    r = requests.get(url, headers=HSGT_HEADERS, timeout=10)
    d = r.json()
    times = d.get("time", [])
    hgt = d.get("hgt", [])
    sgt = d.get("sgt", [])

    n = len(times)
    return pd.DataFrame({
        "time": times,
        "hgt_yi": hgt[:n] + [None] * (n - len(hgt)),
        "sgt_yi": sgt[:n] + [None] * (n - len(sgt)),
    })

# === 自缓存辅助函数 ===

def _northbound_cache_path() -> Path:
    """北向资金本地 CSV 缓存路径"""
    p = Path.home() / ".tradingagents" / "cache" / "northbound_daily.csv"
    p.parent.mkdir(parents=True, exist_ok=True)
    return p

def _save_northbound_snapshot(date: str, hgt: float, sgt: float):
    """写入/更新当天北向收盘数据到 CSV"""
    path = _northbound_cache_path()
    rows = {}
    if path.exists():
        for line in path.read_text().strip().split("\n")[1:]:
            parts = line.split(",")
            if len(parts) == 3:
                rows[parts[0]] = line
    rows[date] = f"{date},{hgt},{sgt}"
    with open(path, "w") as f:
        f.write("date,hgt,sgt\n")
        for d in sorted(rows.keys()):
            f.write(rows[d] + "\n")

def _load_northbound_history(n: int = 20) -> pd.DataFrame:
    """读取最近 N 天北向历史"""
    path = _northbound_cache_path()
    if not path.exists():
        return pd.DataFrame()
    df = pd.read_csv(path)
    return df.tail(n)

# 用法 1: 实时分钟流向
df = hsgt_realtime()
print(f"分钟点数: {len(df)}")
print(df.tail(5))

# 用法 2: 自动缓存今日收盘数据
if not df.empty:
    last = df.dropna().iloc[-1]
    _save_northbound_snapshot("2026-05-17", last["hgt_yi"], last["sgt_yi"])

# 用法 3: 读取历史
hist = _load_northbound_history(20)
print(hist)
```
