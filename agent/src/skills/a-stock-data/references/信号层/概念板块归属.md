# 概念板块归属

> **Vibe-Trading 内置**: 此功能已由 `eastmoney` 技能的 `get_sector_info` 工具覆盖。优先走内置工具。

## 功能说明

一次调用拿到个股所属的全部板块（行业 + 概念 + 地域混合），含板块代码（BK码）、当日涨跌幅、板块龙头股。题材归因、板块联动分析必备。

## 数据源

- **端点**: `https://push2.eastmoney.com/api/qt/slist/get`
- **参数**: `spt=3` 表示个股所属板块（行业/概念/地域混在一个列表返回）
- **鉴权**: 零鉴权，走 `em_get` 限流

## 请求参数

| 参数 | 值 | 说明 |
|------|-----|------|
| `fltt` | `2` | 固定 |
| `invt` | `2` | 固定 |
| `secid` | `{market}.{code}` | market: 1=沪, 0=深 |
| `spt` | `3` | 个股所属板块 |
| `pi` | `0` | 页码 |
| `pz` | `200` | 每页数量 |
| `po` | `1` | 排序 |
| `fields` | `f12,f14,f3,f128` | 返回字段 |

## 返回字段

| 字段 | 含义 |
|------|------|
| `f12` | BK 板块代码 |
| `f14` | 板块名称 |
| `f3` | 板块当日涨跌幅(%) |
| `f128` | 板块龙头股 |

## 代码示例

```python
def eastmoney_concept_blocks(code: str) -> dict:
    """个股所属板块/概念归属（东财 slist，一次请求拿全）。
    返回: {total, boards: [{name, code(BK码), change_pct, lead_stock}], concept_tags: [板块名...]}
    boards 混合 行业/概念/地域，板块名自解释；concept_tags 是所有板块名的便捷列表。
    """
    market_code = 1 if code.startswith("6") else 0
    params = {
        "fltt": "2", "invt": "2",
        "secid": f"{market_code}.{code}",
        "spt": "3", "pi": "0", "pz": "200", "po": "1",
        "fields": "f12,f14,f3,f128",
    }
    headers = {"User-Agent": UA, "Referer": "https://quote.eastmoney.com/"}
    try:
        r = em_get("https://push2.eastmoney.com/api/qt/slist/get",
                   params=params, headers=headers, timeout=15)
        d = r.json()
    except Exception as e:
        print(f"[WARN] 东财板块归属请求失败: {e}")
        return {"total": 0, "boards": [], "concept_tags": []}

    diff = (d.get("data") or {}).get("diff") or {}
    items = diff.values() if isinstance(diff, dict) else diff
    boards = []
    for it in items:
        boards.append({
            "name": it.get("f14", ""),         # 板块名
            "code": it.get("f12", ""),         # BK 板块代码
            "change_pct": it.get("f3", ""),    # 板块当日涨跌幅
            "lead_stock": it.get("f128", ""),  # 板块龙头股
        })
    return {
        "total": len(boards),
        "boards": boards,
        "concept_tags": [b["name"] for b in boards],
    }

# 用法
blocks = eastmoney_concept_blocks("600519")
print(f"共 {blocks['total']} 个板块")
print("板块归属:", blocks["concept_tags"])
# => ['食品饮料', '白酒Ⅲ', '白酒Ⅱ', '贵州板块', '酿酒概念', 'HS300_', ...]
```

## 注意事项

东财不区分行业/概念/地域类型（混在一个列表返回）。如需精确分类可按板块名判断。板块名本身已自解释（如「食品饮料」是行业、「贵州板块」是地域、「酿酒概念」是概念），直接用板块名做题材归因即可。
