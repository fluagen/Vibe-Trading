# 分红送转历史

## 功能说明

查询个股历史分红送转记录，含每股派息（税前）、转增比例、送股比例、实施进度。用于评估股息回报和股本扩张历史。

## 数据源

- **端点**: `https://datacenter-web.eastmoney.com/api/data/v1/get`
- **报表名**: `RPT_SHAREBONUS_DET`
- **鉴权**: 零鉴权，走 `eastmoney_datacenter` 统一入口（自动限流）

## 请求参数

| 参数 | 值 | 说明 |
|------|-----|------|
| `reportName` | `RPT_SHAREBONUS_DET` | 分红送转明细报表 |
| `filter` | `(SECURITY_CODE="{code}")` | 按股票代码过滤 |
| `pageSize` | `20` | 每页数量 |
| `sortColumns` | `EX_DIVIDEND_DATE` | 按除权除息日排序 |
| `sortTypes` | `-1` | 倒序（最新在前） |

## 返回字段

| 字段 | 含义 | 单位 |
|------|------|------|
| `EX_DIVIDEND_DATE` | 除权除息日 | - |
| `PRETAX_BONUS_RMB` | 每股派息（税前） | 元 |
| `TRANSFER_RATIO` | 转增比例 | 每10股转增股数 |
| `BONUS_RATIO` | 送股比例 | 每10股送股数 |
| `ASSIGN_PROGRESS` | 实施进度 | - |

## 代码示例

```python
def dividend_history(code: str, page_size: int = 20) -> list[dict]:
    """分红送转历史。
    返回: [{date, bonus_rmb(每股派息), transfer_ratio(转增比例), bonus_ratio(送股比例)}]
    """
    data = eastmoney_datacenter(
        "RPT_SHAREBONUS_DET",
        filter_str=f'(SECURITY_CODE="{code}")',
        page_size=page_size,
        sort_columns="EX_DIVIDEND_DATE", sort_types="-1",
    )
    rows = []
    for row in data:
        rows.append({
            "date": str(row.get("EX_DIVIDEND_DATE", ""))[:10],
            "bonus_rmb": row.get("PRETAX_BONUS_RMB", 0),    # 每股派息(税前)
            "transfer_ratio": row.get("TRANSFER_RATIO", 0),  # 每10股转增
            "bonus_ratio": row.get("BONUS_RATIO", 0),        # 每10股送股
            "plan": row.get("ASSIGN_PROGRESS", ""),           # 进度
        })
    return rows

# 用法
data = dividend_history("600519")
for d in data[:5]:
    print(f"{d['date']}: 每股派息={d['bonus_rmb']}元 转增={d['transfer_ratio']} 送={d['bonus_ratio']}")
```

## 分析要点

- 连续多年稳定派息 = 现金流健康、治理良好
- 高转增/送股 = 股本扩张，降低绝对股价，增加流动性
- 股息率 = `bonus_rmb / 当前股价 * 100%`，与国债收益率比较
- 派息率突然大幅变动需关注原因（一次性特别分红 vs 经营恶化）
