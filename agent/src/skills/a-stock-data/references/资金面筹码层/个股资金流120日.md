# 个股资金流（120日，日级）

> **Vibe-Trading 内置**: 此功能已由 `eastmoney` 技能的 `get_fund_flow` 工具覆盖（参数 `days=120`）。

## 功能说明

查询个股最近 120 个交易日的日级资金流向，含主力净流入、小单/中单/大单/超大单净流入。用于判断中期主力资金态度和资金结构。

## 数据源

- **端点**: `https://push2his.eastmoney.com/api/qt/stock/fflow/daykline/get`
- **鉴权**: 零鉴权，走 `em_get` 限流
- **注意**: push2his 对部分大陆住宅 IP 有间歇风控（偶发 `HTTP 000`），非代码问题

## 请求参数

| 参数 | 值 | 说明 |
|------|-----|------|
| `secid` | `{market}.{code}` | market: 1=沪, 0=深 |
| `fields1` | `f1,f2,f3,f7` | 固定字段 |
| `fields2` | `f51,f52,f53,f54,f55,f56,f57,f58,f59,f60,f61,f62,f63,f64,f65` | 数据字段（CSV格式返回） |
| `lmt` | `120` | 最近120个交易日 |

## 返回字段（`fields2` 逗号分隔的 CSV 行）

| 位置 | 字段 | 含义 | 单位 |
|------|------|------|------|
| 0 | `date` | 交易日期 | - |
| 1 | `main_net` | 主力净流入 | 元 |
| 2 | `small_net` | 小单净流入 | 元 |
| 3 | `mid_net` | 中单净流入 | 元 |
| 4 | `large_net` | 大单净流入 | 元 |
| 5 | `super_net` | 超大单净流入 | 元 |

## 代码示例

```python
def stock_fund_flow_120d(code: str) -> list[dict]:
    """个股资金流（日级，最近120个交易日）。
    返回: [{date, main_net(主力净流入), small_net, mid_net, large_net, super_net}]
    单位: 元
    """
    market_code = 1 if code.startswith("6") else 0
    url = "https://push2his.eastmoney.com/api/qt/stock/fflow/daykline/get"
    params = {
        "secid": f"{market_code}.{code}",
        "fields1": "f1,f2,f3,f7",
        "fields2": "f51,f52,f53,f54,f55,f56,f57,f58,f59,f60,f61,f62,f63,f64,f65",
        "lmt": "120",
    }
    headers = {
        "User-Agent": UA,
        "Referer": "https://quote.eastmoney.com/",
        "Origin": "https://quote.eastmoney.com",
    }
    try:
        r = em_get(url, params=params, headers=headers, timeout=15)
        d = r.json()
    except Exception as e:
        print(f"[WARN] push2 资金流请求失败: {e}")
        return []
    klines = d.get("data", {}).get("klines", [])

    rows = []
    for line in klines:
        parts = line.split(",")
        if len(parts) >= 7:
            rows.append({
                "date": parts[0],
                "main_net": float(parts[1]) if parts[1] != "-" else 0,
                "small_net": float(parts[2]) if parts[2] != "-" else 0,
                "mid_net": float(parts[3]) if parts[3] != "-" else 0,
                "large_net": float(parts[4]) if parts[4] != "-" else 0,
                "super_net": float(parts[5]) if parts[5] != "-" else 0,
            })
    return rows

# 用法
data = stock_fund_flow_120d("600519")
for d in data[-5:]:
    print(f"{d['date']}: 主力净流入={d['main_net']/1e4:.0f}万 超大单={d['super_net']/1e4:.0f}万")

# 统计近20日主力净流入
recent_20 = data[-20:]
total_main = sum(d["main_net"] for d in recent_20)
print(f"\n近20日主力累计净流入: {total_main/1e8:.2f}亿")
```

## 分析要点

- 主力净流入（`main_net`）= 超大单 + 大单净流入
- 连续多日主力净流入 + 股价横盘 = 主力吸筹
- 主力净流入为正但股价下跌 = 散户恐慌抛售、主力接盘
- 主力净流出持续 = 机构减仓
- 风控说明：push2his 对部分大陆住宅宽带 IP 有间歇封锁，遇 `HTTP 000` 时隔几分钟重试或换网络环境
