# 股东户数变化

> **Vibe-Trading 内置**: 此功能已由 `eastmoney` 技能的 `get_shareholder_count` 工具覆盖。

## 功能说明

查询个股季度级股东户数变化，含股东数、环比变化数量/比例、户均持股。股东户数持续减少 = 筹码趋于集中 = 主力吸筹信号；户数增加 = 筹码分散。

## 数据源

- **端点**: `https://datacenter-web.eastmoney.com/api/data/v1/get`
- **报表名**: `RPT_HOLDERNUMLATEST`
- **鉴权**: 零鉴权，走 `eastmoney_datacenter` 统一入口（自动限流）

## 请求参数

| 参数 | 值 | 说明 |
|------|-----|------|
| `reportName` | `RPT_HOLDERNUMLATEST` | 股东户数最新报表 |
| `filter` | `(SECURITY_CODE="{code}")` | 按股票代码过滤 |
| `pageSize` | `10` | 每页数量（约10个季度） |
| `sortColumns` | `END_DATE` | 按报告期排序 |
| `sortTypes` | `-1` | 倒序（最新在前） |

## 返回字段

| 字段 | 含义 |
|------|------|
| `END_DATE` | 报告截止日期 |
| `HOLDER_NUM` | 股东户数 |
| `HOLDER_NUM_CHANGE` | 股东户数变化（环比） |
| `HOLDER_NUM_RATIO` | 股东户数变化率(%) |
| `AVG_FREE_SHARES` | 户均持股数 |

## 代码示例

```python
def holder_num_change(code: str, page_size: int = 10) -> list[dict]:
    """股东户数变化（季度级）。
    返回: [{date, holder_num, change_num, change_ratio, avg_shares}]
    """
    data = eastmoney_datacenter(
        "RPT_HOLDERNUMLATEST",
        filter_str=f'(SECURITY_CODE="{code}")',
        page_size=page_size,
        sort_columns="END_DATE", sort_types="-1",
    )
    rows = []
    for row in data:
        rows.append({
            "date": str(row.get("END_DATE", ""))[:10],
            "holder_num": row.get("HOLDER_NUM", 0),
            "change_num": row.get("HOLDER_NUM_CHANGE", 0),
            "change_ratio": row.get("HOLDER_NUM_RATIO", 0),  # 环比%
            "avg_shares": row.get("AVG_FREE_SHARES", 0),     # 户均持股
        })
    return rows

# 用法
data = holder_num_change("600519")
for d in data[:5]:
    print(f"{d['date']}: 股东数={d['holder_num']} 变化={d['change_ratio']}% 户均={d['avg_shares']}")
# 股东户数持续减少 = 筹码集中 = 主力吸筹信号
```

## 分析要点

- 股东户数连续 3 个季度减少 + 户均持股增加 = 筹码集中，偏多
- 股东户数大幅增加 = 筹码分散，可能为主力出货
- 结合股价位置：低位集中偏吸筹、高位集中偏锁仓
