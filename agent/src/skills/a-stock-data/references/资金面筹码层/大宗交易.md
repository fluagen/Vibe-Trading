# 大宗交易

> **Vibe-Trading 内置**: 此功能已由 `eastmoney` 技能的 `get_block_trades` 工具覆盖。

## 功能说明

查询个股大宗交易记录，含成交价、成交量、买卖双方席位、相对收盘溢价率。大宗交易折溢价反映机构态度——溢价买入偏多、折价卖出偏空。

## 数据源

- **端点**: `https://datacenter-web.eastmoney.com/api/data/v1/get`
- **报表名**: `RPT_DATA_BLOCKTRADE`
- **鉴权**: 零鉴权，走 `eastmoney_datacenter` 统一入口（自动限流）

## 请求参数

| 参数 | 值 | 说明 |
|------|-----|------|
| `reportName` | `RPT_DATA_BLOCKTRADE` | 大宗交易报表 |
| `filter` | `(SECURITY_CODE="{code}")` | 按股票代码过滤 |
| `pageSize` | `20` | 每页数量 |
| `sortColumns` | `TRADE_DATE` | 按交易日排序 |
| `sortTypes` | `-1` | 倒序（最新在前） |

## 返回字段

| 字段 | 含义 |
|------|------|
| `TRADE_DATE` | 交易日期 |
| `DEAL_PRICE` | 成交价格 |
| `CLOSE_PRICE` | 当日收盘价 |
| `premium_pct` | 溢价率(%)，计算值: (成交价/收盘价 - 1)*100 |
| `DEAL_VOLUME` | 成交量(股) |
| `DEAL_AMT` | 成交额(元) |
| `BUYER_NAME` | 买方营业部 |
| `SELLER_NAME` | 卖方营业部 |

## 代码示例

```python
def block_trade(code: str, page_size: int = 20) -> list[dict]:
    """大宗交易记录。
    返回: [{date, price, vol, amount, buyer, seller, premium_pct}]
    """
    data = eastmoney_datacenter(
        "RPT_DATA_BLOCKTRADE",
        filter_str=f'(SECURITY_CODE="{code}")',
        page_size=page_size,
        sort_columns="TRADE_DATE", sort_types="-1",
    )
    rows = []
    for row in data:
        close = row.get("CLOSE_PRICE") or 0
        deal_price = row.get("DEAL_PRICE") or 0
        premium = ((deal_price / close - 1) * 100) if close else 0
        rows.append({
            "date": str(row.get("TRADE_DATE", ""))[:10],
            "price": deal_price,
            "close": close,
            "premium_pct": round(premium, 2),
            "vol": row.get("DEAL_VOLUME", 0),
            "amount": row.get("DEAL_AMT", 0),
            "buyer": row.get("BUYER_NAME", ""),
            "seller": row.get("SELLER_NAME", ""),
        })
    return rows

# 用法
data = block_trade("600519")
for d in data[:5]:
    print(f"{d['date']}: 价格={d['price']} 溢价={d['premium_pct']}% 买方={d['buyer']}")
```

## 分析要点

- 溢价率 > 0：买方愿意高于市价接盘，偏多
- 溢价率 < -5%：折价甩卖，需关注卖方动机
- 同一营业部频繁出现：可能有固定交易对手
