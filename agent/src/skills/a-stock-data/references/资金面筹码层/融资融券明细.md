# 融资融券明细

> **Vibe-Trading 内置**: 此功能已由 `eastmoney` 技能的 `get_margin_trading` 工具覆盖。

## 功能说明

查询个股日级融资融券明细，包括融资余额、融资买入/偿还额、融券余额、融券卖出/偿还量。用于跟踪杠杆资金多空动向。

## 数据源

- **端点**: `https://datacenter-web.eastmoney.com/api/data/v1/get`
- **报表名**: `RPTA_WEB_RZRQ_GGMX`
- **鉴权**: 零鉴权，走 `eastmoney_datacenter` 统一入口（自动限流）

## 请求参数

| 参数 | 值 | 说明 |
|------|-----|------|
| `reportName` | `RPTA_WEB_RZRQ_GGMX` | 融资融券个股明细 |
| `filter` | `(SCODE="{code}")` | 按股票代码过滤 |
| `pageSize` | `30` | 每页数量 |
| `sortColumns` | `DATE` | 按日期排序 |
| `sortTypes` | `-1` | 倒序（最新在前） |

## 返回字段

| 字段 | 含义 | 单位 |
|------|------|------|
| `DATE` | 交易日期 | - |
| `RZYE` | 融资余额 | 元 |
| `RZMRE` | 融资买入额 | 元 |
| `RZCHE` | 融资偿还额 | 元 |
| `RQYE` | 融券余额 | 元 |
| `RQMCL` | 融券卖出量 | 股 |
| `RQCHL` | 融券偿还量 | 股 |
| `RZRQYE` | 融资融券余额合计 | 元 |

## 代码示例

```python
def margin_trading(code: str, page_size: int = 30) -> list[dict]:
    """融资融券明细（日级）。
    返回: [{date, rzye(融资余额), rzmre(融资买入), rqye(融券余额), ...}]
    """
    data = eastmoney_datacenter(
        "RPTA_WEB_RZRQ_GGMX",
        filter_str=f'(SCODE="{code}")',
        page_size=page_size,
        sort_columns="DATE", sort_types="-1",
    )
    rows = []
    for row in data:
        rows.append({
            "date": str(row.get("DATE", ""))[:10],
            "rzye": row.get("RZYE", 0),       # 融资余额(元)
            "rzmre": row.get("RZMRE", 0),      # 融资买入额
            "rzche": row.get("RZCHE", 0),      # 融资偿还额
            "rqye": row.get("RQYE", 0),        # 融券余额(元)
            "rqmcl": row.get("RQMCL", 0),      # 融券卖出量
            "rqchl": row.get("RQCHL", 0),      # 融券偿还量
            "rzrqye": row.get("RZRQYE", 0),    # 融资融券余额合计
        })
    return rows

# 用法
data = margin_trading("600519")
for d in data[:5]:
    print(f"{d['date']}: 融资余额={d['rzye']/1e8:.2f}亿 融券余额={d['rqye']/1e8:.2f}亿")
```

## 分析要点

- 融资余额持续增长 = 多头加杠杆 = 看涨信号
- 融券余额飙升 = 空头聚集 = 看空信号
- 融资买入额 / 融资偿还额 > 1 = 当日净融资流入
