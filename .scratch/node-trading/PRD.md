# 节点交易策略框架

> Status: `ready-for-agent` | Created: 2026-08-11 | Updated: 2026-08-12 (3节点重构)

## Problem Statement

交易员面对一个核心难题：同一只股票在不同走势阶段，同样的技术信号（如上穿 MA20）有完全不同的胜率。在均线粘合震荡期追突破容易被反复骗线，在趋势加速期追高容易被套在山顶，只有在健康趋势期的信号才具有高胜率。

现有策略（如 `up_trend_structure`、`trend-phase`）只提供单一维度的入场信号，缺乏"先判断市场阶段、再决定是否交易、最后决定交易多少"的分层决策体系。交易员需要一个框架，能自动识别标的处于生命周期的哪个阶段，并在正确的阶段执行正确的节点交易。

## Solution

节点交易策略框架将走势划分为五个阶段（S1 蓄势 → S2 萌芽 → S3 健康趋势 → S4 加速 → S5 极端），在 S3（健康趋势期）重仓出击，在 S2（萌芽期）轻仓试错，在 S4（加速期）谨慎开仓，在 S5（极端期）只卖不买，在 S1（蓄势期）空仓观望（仅允许粘合爆发试错）。

策略使用三个核心指标（极差比 R、变异系数 CV、极差比斜率 RS）量化阶段边界，定义三种节点（反转、支撑、粘合爆发）作为入场信号，并配套动态仓位管理和分级止盈止损规则。

## User Stories

1. As a 交易员, I want 系统自动判定当前处于哪个走势阶段 (S1-S5), so that 我不需要手动判断市场状态
2. As a 交易员, I want 在 S3 健康趋势期自动识别回踩 MA20 的支撑节点, so that 我能在最佳时机重仓出击
3. As a 交易员, I want 在 S2 萌芽期只允许轻仓试错反转节点, so that 我不会在弱趋势中过度暴露风险
4. As a 交易员, I want 在 S4 加速期谨慎开仓（反转+支撑均可）, so that 我不会追高被套
5. As a 交易员, I want 在 S1 蓄势震荡期空仓观望（仅允许粘合爆发的极小仓位试错）, so that 我避免在无趋势市场中反复亏损
6. As a 交易员, I want 系统在 S3/S4/S5 阶段使用 R 分层止盈（R 越高止盈越敏锐，R 越低越迟钝），S1/S2 不触发止盈只靠止损离场, so that 均线发散时果断锁利、均线粘合时扛过震荡
7. As a 交易员, I want 加速期 S4(bull)/S5(bull) 使用更紧的止盈（MA5 减半 → MA10 全清）, so that 我能及时锁定极端行情的利润
8. As a 交易员, I want 硬止损 -5% 和节点失败止损自动执行, so that 单笔亏损不会失控
9. As a 交易员, I want 反转节点在入场 3 日内触发节点失败止损（支撑和粘合爆发无限期）, so that 不同节点类型有差异化的风控规则
10. As a 交易员, I want 下跌阶段出现的放量上穿 MA20 被识别为反转节点, so that 我能捕捉 V 型反转机会
11. As a 策略研究员, I want 所有阈值参数可配置, so that 我能回测调参优化策略
12. As a 策略研究员, I want 对单只股票快速跑回测并查看 equity curve 和 trade log, so that 我能直观验证策略效果

## Implementation Decisions

### 模块架构

策略按照 **指标 → 阶段分类 → 节点检测 → 仓位管理 → 风控** 五层分解，每层是独立的纯函数模块，顶层 SignalEngine 组合所有模块并维护逐 bar 状态机。

### 状态管理

SignalEngine 内部维护持仓状态（入场价、入场日期、节点类型、已减仓次数），每根 bar 按固定顺序推进：先检查止损止盈（平旧仓），再判定阶段和扫描节点（开新仓），最后输出信号。与 `up_trend_structure` 的状态机模式一致。

**上个阶段追踪**：支撑节点和反转节点的"上个阶段"指最近一个有明确方向（bull/bear）的 bar 的阶段和方向，跳过所有 crossed（穿插震荡）的 bar。初始值默认为 S1(crossed)，仅在遇到 alignment 为 bull 或 bear 的 bar 时更新。

### 信号编码

信号值 = 目标仓位成数的绝对值（0.7 / 0.5 / 0.2 / 0.1 / 0.0），`-1.0` = 强制清仓。回测引擎在 `_align()` 中做截面 L1 归一化（`sum(abs) ≤ 1.0`），单标的场景不受影响（因为 `clip(lower=1.0)` 对 ≤1.0 的值原样保留）。

### 参数配置

所有 PRD 阈值作为 `SignalEngine.__init__` 参数传入并带有默认值，满足回测引擎 `SignalEngine()` 无参构造要求。

### 核心指标体系

三个核心指标基于 MA5/MA10/MA20 三条均线：

- **极差比 R** = (max(MA5,MA10,MA20) − min) / mean × 100% — 衡量均线间距（趋势能量）
- **变异系数 CV** = std(MA5,MA10,MA20) / mean — 衡量发散均匀度
- **极差比斜率 RS** = R / R_5d_ago — 衡量趋势加速速度

方向定义：
- **bull**（多头）：MA5 > MA10 > MA20
- **bear**（空头）：MA5 < MA10 < MA20
- **crossed**（穿插震荡）：均线无明确排列

### 五阶段判定（自上而下优先级）

```
IF R > 9% AND CV > 0.4 → S5（极端赶顶/赶底）
ELIF R > 6% OR RS ≥ 1.1 → S4（趋势加速）
ELIF 均线排列 AND 4% < R ≤ 6% AND RS < 1.1 AND CV < 0.3 → S3（健康趋势）
ELIF 均线排列 AND 2% < R ≤ 4% AND NOT S3 → S2（趋势萌芽）
ELSE → S1（蓄势粘合/宽幅震荡）
```

### 三种节点触发条件

| 节点 | 触发条件 | 特殊过滤 |
|------|----------|----------|
| 反转节点（V型反转） | ① 上穿MA20收阳（Open<MA20<High 且 Close>Open）② 放量（Vol>Prev_Vol）③ 上个阶段方向 bear | S2 阶段附加：R > 2.5% |
| 支撑节点（上涨中继） | ① 回踩MA20收阳（Low<MA20×1.005 且 Close>MA20×1.005 且 Close>Open）② 上个阶段 S3/S4 且方向 bull | — |
| S1粘合爆发（横盘突破） | ① 上穿MA20收阳（Open<MA20<Close 且 Close>Open）② 放量（Vol>Prev_Vol×1.5）③ 当前 S1 阶段 | — |

### 仓位与阶段联动

| 阶段 | 总仓上限 | 允许节点 | 说明 |
|------|----------|----------|------|
| S1 | 1成 | 仅粘合爆发 | 试错 |
| S2 | 2成 | 仅反转 | 轻仓试错 |
| S3(bull) | 7成 | 反转+支撑(5成) | 核心重仓区 |
| S4(bull) | 3成 | 反转+支撑(3成) | 加速期，谨慎 |
| S4(bear/crossed) | 2成 | 反转 | 允许试错 |
| S5 | 0成 | 无 | 禁买区 |

反转节点仓位按 R 值分级：R≤6% → 2成，R>6% → 1成。

### 止损规则（按节点类型）

| 节点类型 | 止损规则 |
|----------|----------|
| 反转节点 | 硬性止损 -5%；3 日内节点失败止损 |
| 支撑节点 | 硬性止损 -5% + 节点失败止损 |
| S1粘合爆发 | 硬性止损 -5% + 节点失败止损 |

1. **硬性止损**：相对买入价下跌 -5% → 无条件离场
2. **节点失败止损**：Close < 节点K线最低价 → 离场。反转节点仅入场后 3 个交易日内触发

### 止盈规则（R 分层控制灵敏度）

止盈不限制方向（bull/bear/crossed 均可触发），通过 R 值（均线离散度）分层控制止盈灵敏度。

| 触发阶段 | R 区间 | 第一止盈位 | 第二止盈位 |
|----------|--------|-----------|-----------|
| S4/S5 加速期 | R > 9%（极端发散） | Close < MA5 → 减半 | Close < MA10 → 全清 |
| S4/S5 加速期 | 6% < R ≤ 9%（一般发散） | Close < MA10 → 减半 | Close < MA20 → 全清 |
| S4/S5 加速期 | R ≤ 6%（趋近粘合） | — | Close < MA20 → 全清 |
| S3 正常期 | — | Close < MA10 → 减半 | Close < MA20 → 全清 |

S1/S2 不触发止盈，仅靠止损规则离场。

### 计算架构

矢量化预计算 + 逐 bar 状态机。指标全部一次性算出（纯函数），SignalEngine 遍历预计算结果做状态推进和决策。

### 单标快速验证

提供独立的验证脚本，可以加载单只股票数据、跑完整回测、输出 equity curve / trade log / metrics summary。

## Testing Decisions

### 测试策略

只测试外部行为，不测试内部实现细节。核心覆盖：指标计算正确性和阶段判定逻辑。

### Test Seams

| Seam | 层级 | 测试内容 |
|------|------|----------|
| `compute_indicators(df)` | 单元 | R/CV/RS/均线排列/上穿MA20 计算正确性 |
| `classify_stage(row)` | 单元 | 已知指标值 → 断言阶段 S1-S5 |
| `SignalEngine.generate(data_map)` | 集成 | 已知 OHLCV → 断言特定日期信号值 |

### Prior Art

`agent/tests/test_structure_signal_engine.py` — 直接测试 SignalEngine.generate() 输出，覆盖入场/止损/止盈信号。

### 测试文件

- `tests/test_indicators.py` — R/CV/RS/排列/上穿计算
- `tests/test_stage_classifier.py` — 五阶段判定优先级和边界条件

## Out of Scope

- 多标的截面资金分配（当前按单标的回测）
- 与 live trading 系统的集成（mandate/kill-switch 对接）
- 前端可视化（阶段颜色标注、节点标记在 K 线图上）
- 因子 zoo 注册（暂不作为独立因子，策略内部使用）
- `.scratch/trend-phase/1.md` 的 BIAS 六阶段体系（完全不同的策略，不参考）
- 大盘共振过滤（如沪深300 MA60 方向过滤）

## Further Notes

- 这套策略与现有 `trend-phase`（BIAS 六阶段）和 `up_trend_structure`（止跌K/证伪K）是完全独立的三套体系，不存在代码复用关系
- 策略采用当日尾盘执行（同日 bar），回测不做 shift，信号与收盘价同 bar 生效
- 所有阈值参数来自 PRD 文档，后续回测可能需要根据实际数据分布调整
- 2026-08-12 重构：从 4 节点（常规反转、下跌终结、支撑、粘合爆发）简化为 3 节点（反转节点合并了常规反转+下跌终结），止损统一为 -5%
