# MA 均线粘合判断

判断 MA5/MA10/MA20 三条均线是否粘合，有几种常用方法：

## 方法

| 方法 | 公式 | 含义 |
|------|------|------|
| **极差比**（最常用） | `(max(MA5,MA10,MA20) − min(MA5,MA10,MA20)) / close` | 三条均线的最大间距占股价的百分比 |
| **变异系数** | `std(MA5,MA10,MA20) / mean(MA5,MA10,MA20)` | 三条均线的离散程度 |
| **两两距离** | 任意两条差值 < 阈值 | 全部成对接近才判定粘合 |

## 极差比（推荐）

```python
ma5  = close.rolling(5).mean()
ma10 = close.rolling(10).mean()
ma20 = close.rolling(20).mean()

# 三条均线的最高值与最低值的差
ma_max = np.maximum(np.maximum(ma5, ma10), ma20)
ma_min = np.minimum(np.minimum(ma5, ma10), ma20)

# 三条均线的平均值
ma_mean = (ma5 + ma10 + ma20) / 3

# 除以均线的平均值，得到百分比
spread_pct = (ma_max - ma_min) / ma_mean


# 极差小于 2% 视为粘合
is_sticky = spread_pct < 0.02
```

## 为什么用极差比而不是两两距离？

两两距离的问题在于**传递性不成立**：MA5 离 MA10 差 1.5%，MA10 离 MA20 差 1.5%，但 MA5 离 MA20 可能已经差了 3%——三条均线实际上已经发散了。

极差比直接看**最外层两条的距离**，不会漏判。

## 粘合阈值选取

| 阈值 | 含义 | 适用场景 |
|------|------|---------|
| `< 1%` | 极度粘合 | 大爆发前夜，信号少但精准 |
| `< 2%` | 明显粘合 | 常见盘整末端 |
| `< 3%` | 松散粘合 | 宽幅震荡中的均线收敛 |

实际使用中通常取 **2%** —— 太严信号太少，太松假信号多。

## 在策略中的用法

粘合期是**方向不明**的阶段，应该：

> **不做方向判断，维持当前仓位**

这跟策略中已有的 `sticky` 逻辑一致——粘合时不加仓不减仓，等均线重新发散后再跟方向。

## 与现有策略的关系

防守型/进攻型趋势阶段策略中，已包含 MA20 与 MA60 的粘合检测：

```python
abs(ma20 - ma60) / ma60 < 0.015   # 差值比 < 1.5% 视为粘合
```

MA5/MA10/MA20 粘合适用于短线方向选择（数周内），MA20/MA60 粘合适用于中线趋势判断（数月内）。两条粘合信号可叠加使用，双重粘合意味着更强烈的方向突破预期。

## 变异系数（CV）与极差比对比

### 原理差异

**极差比**只看最外层两条均线：

```
(max − min) / close
```

分子是 MA5、MA10、MA20 中最大与最小的差值，不关心中间那条的位置。

**变异系数**利用全部三条线的分布信息：

```
std(MA5, MA10, MA20) / mean(MA5, MA10, MA20)
```

分子是三者的标准差，分母是均值。CV 假设：三条线越离散，std 越大，CV 越大。

### CV 的优势：量纲无关

同一粘合程度在不同股价下，`std` 绝对值相差悬殊：

```
¥10 股:  MA5=10.0  MA10=9.8  MA20=9.5   → std ≈ 0.25
¥100股:  MA5=100   MA10=98   MA20=95    → std ≈ 2.5
```

但除以各自的 mean 后：

```
¥10 股:  CV = 0.25 / 9.77  ≈ 2.6%
¥100股:  CV = 2.5  / 97.7  ≈ 2.6%   ← 同一尺度
```

极差比除以的是 `close`，而 CV 除以的是三条均线的 `mean`。两者都实现了归一化。

### CV 的弱点：均匀分布假象

三条均线均匀排列（等距发散）时，CV 会误判为粘合：

```
情形：多头发散（非粘合）
  MA5  = 15  ─────────
  MA10 = 13     ─────────
  MA20 = 11        ─────────

  极差 = (15-11)/close ≈ 很大 → 非粘合 ✓ 正确
  mean = 13，std(15,13,11) 被"均匀"这个特性压制 → CV 小 → 判粘合 ✗ 误判
```

当三条线等距分布时，标准差只反映间距的固定偏移量，除以均值后得到一个偏小的 CV，掩盖了实际已经发散的事实。

极差比不受此影响——它只看 MA5 和 MA20 的真实距离，不关心中间 MA10 的位置。

### 总结

| 维度 | 极差比 | 变异系数 |
|------|--------|---------|
| 关注点 | 最外层两条的距离 | 三条线的整体离散度 |
| 归一化 | `/ close` | `/ mean(三条线)` |
| 均匀发散误判 | 不会 | **会** |
| 三条线信息利用 | 只用了两条 | 全部三条 |
| 推荐场景 | 通用，鲁棒 | 横盘震荡期辅助参考 |

**优先使用极差比，CV 作为辅助确认。**
